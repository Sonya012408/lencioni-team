# Пять пороков команды — разбор бизнес-романа

Лонгрид-разбор книги Патрика Ленсиони «Пять пороков команды» (МИФ, 2016).

**Открыть:** https://sonya012408.github.io/lencioni-team/

## Что внутри

- Сюжет романа о DecisionTech: пролог, Кэтрин Питерсен, восемь топ-менеджеров, развязка
- Модель пяти пороков в виде пирамиды: недоверие → уход от конфликтов → необязательность → нетребовательность → безразличие к результату
- По каждому пороку: определение, два списка «где есть / где нет», упражнения с таймингом, роль лидера, сцена из романа
- **Интерактивная анкета из 15 вопросов** с подсчётом по каждому пороку прямо в браузере
- Календарь выездных совещаний Кэтрин, 10 принципов, словарь из 12 терминов
- 15 фотографий из Wikimedia Commons с указанием авторов и лицензий
- PDF-версия в формате 16:9 — 49 полос, живой текст

## Технически

Одна статическая страница без зависимостей. Шрифты — Playfair Display и Inter (Google Fonts). Изображения хранятся в репозитории. Печатный стилевой блок даёт слайды 13,333 × 7,5 дюйма.
